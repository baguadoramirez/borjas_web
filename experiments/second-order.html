Movimiento de Segundo Orden

Esta página explica el movimiento de segundo orden, un fenómeno de percepción visual en el que detectamos movimiento sin un borde de luminancia definido.

En lugar de cambiar la luz de un contorno, lo que cambia es la textura interna del objeto respecto al fondo.

La demo de abajo permite observar cómo el sistema visual usa ese cambio de textura para percibir desplazamiento.

Demo interactiva

El fondo es ruido estático y el cuadrado es otro parche de ruido que se desplaza.

Cuando el cuadrado se mueve, la textura cambia de posición pero el brillo medio no define un borde visible.

Aun así, el movimiento se percibe porque el sistema visual sigue el desplazamiento del patrón interno.

El cuadrado se mueve durante 2 segundos y se detiene otros 2 segundos de forma cíclica.

Que observar

  • El cuadrado no se define por un borde brillante, sino por la organizacion del ruido.
  • El movimiento se hace visible al comparar la textura del parche con la del fondo.
  • En fases de pausa, el parche sigue siendo perceptible aunque no haya desplazamiento.

Este efecto muestra que la percepcion del movimiento no depende solo de cambios de luminancia, sino tambien de cambios en la estructura de la escena.

En psicofisica se usa para estudiar como el sistema visual integra informacion de textura y movimiento en ausencia de contornos claros.
